# 不妊治療における食事・栄養素・生活習慣介入のエビデンス整理

本リポジトリは、不妊治療における食事、栄養素（サプリメント）、生活習慣への介入に関する最新のヒト臨床試験（RCTやメタ解析）のエビデンスを客観的に整理したレポートを公開しています。

## 🎯 対象読者
- 産婦人科・泌尿器科の医師、薬剤師、看護師、胚培養士などの医療従事者
- サプリメント開発・販売に関わるヘルスケア事業者
- 生殖医療における栄養介入のエビデンスを深めたい研究者・専門家

## 💡 本レポートの重要なメッセージ
本レポート全体を通じた最大の結論は、**「精液所見や精子DNA断片化（DFI）、採卵数といった『中間アウトカム』の改善が、必ずしも『妊娠・生産（Live birth）』という最終アウトカムの改善を保証するものではない」**という点です。
有望なシグナルを示す介入（CoQ10など）と、大型RCTにより評価が見直された介入（DHEAなど）を明確に区別し、最新の知見（2026年9月時点）に基づき評価しています。
